# Reference-free harm audit

150 BEA-2019 development outputs of the earlier-configuration final system (`outputs/bea_dev/earlier_config/final.txt`), 50 per reference-distance class (improved, lateral, harm). Each item shows the source sentence and the system output in random order (`output_position`); the judge chose the better English sentence (`1`, `2` or `same`) and whether the meaning is preserved.

**The judgments were made by an AI model (Claude, Anthropic), blind to the key -- this is an AI annotation, not a human assessment.** The sentence texts are not redistributed (W&I+LOCNESS licence); rebuild the sheet from `bea_dev_index` and the released outputs.
